# WCAG AA High-Contrast Dark Theme Color Token Standards

## 1. Color Palette Tokens
- Background: `#0a0b0e` (Deep Void Black).
- Card Surface: `#12151c` with `#1e2330` border accents.
- Primary Accent: `#0891b2` (Cyan-600) — delivers `4.8:1` contrast ratio against dark backgrounds.
- Body Typography: `#e2e8f0` (Slate-200) — delivers `13.5:1` contrast ratio, comfortably exceeding WCAG AAA standards.
