# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability with this web application or any embedded interactive components, please report it via email to:

**ronitgupta138@gmail.com**

Please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and exploit scenario.

You will receive an acknowledgment within 24–48 hours, followed by coordinated updates and fixes.
